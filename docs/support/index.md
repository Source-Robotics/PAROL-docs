# Getting help

- **Questions and discussion**: the [Source Robotics Discord](https://discord.gg/prjUvjmGpZ).
- **A problem with the robot's hardware, its files or the control board firmware**: an issue in the
  [robot repository](https://github.com/Source-Robotics/PAROL6-Desktop-robot-arm/issues); see
  [Report a problem](report-a-problem.md) for what to include.
- **A problem with the commander software**: an issue in
  [PAROL-commander-software](https://github.com/Source-Robotics/PAROL-commander-software/issues).
- **A problem with the Python API**: an issue in [PAROL6-python-API](https://github.com/PCrnjak/PAROL6-python-API/issues).
- **A mistake on a page of this site**: every page ends with a link to edit it and one to report it; see
  [Contributing](contributing.md).
- **Orders and hardware**: [source-robotics.com](https://source-robotics.com/).

Before you ask, [Troubleshooting](../08-troubleshooting/index.md) goes through the common symptoms, and the
commander's terminal output or the API's `error()` tells most of what anyone will ask you for.
