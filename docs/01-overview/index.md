# 1. Overview

PAROL6 is a 3D-printed six-axis desktop robotic arm with a 408 mm reach and a 1 kg payload. It is built to work
like an industrial arm in its mechanics, its control software and the way you use it.

Everything about it is open source: the printable parts, the bill of materials, the control board's firmware, the
commander software and the Python API.

| Get it | |
|---|---|
| [Assembled](https://source-robotics.com/products/parol6-robotic-arm) | Built, wired and tested |
| As the [full kit](https://source-robotics.com/products/parol6-robotic-arm-kit) | Every part except the printed parts and the power supply |
| As the [partial kit](https://source-robotics.com/products/parol6-partial-kit) | The hard-to-find parts |
| Print and build it | From the published files |
