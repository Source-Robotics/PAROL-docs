*[DOF]: Degrees Of Freedom, the number of independent joints
*[TCP]: Tool Center Point, the point on the tool that the robot positions
*[TRF]: Tool Reference Frame, the coordinate frame fixed to the tool
*[WRF]: World Reference Frame, the coordinate frame fixed to the robot's base
*[DH]: Denavit-Hartenberg, the convention that describes a robot's geometry with four numbers per joint
*[FK]: Forward Kinematics, from joint angles to the pose of the tool
*[IK]: Inverse Kinematics, from a pose of the tool to joint angles
*[CAN]: Controller Area Network, the bus between the control board and the electric grippers
*[UART]: a serial port
*[USB]: Universal Serial Bus, the connection between the control board and the PC
*[UDP]: User Datagram Protocol, the network transport between the Python API's clients and its controller
*[BOM]: Bill Of Materials, the list of parts to buy
*[STL]: the file format of the printable parts
*[STEP]: the CAD exchange format of the mechanical parts
*[PETG]: the filament the robot is printed in
*[URDF]: Unified Robot Description Format, the robot description used by ROS 2 and the Python API
*[MJCF]: MuJoCo's robot description format
*[ROS]: Robot Operating System
*[LED]: Light-Emitting Diode
*[NC]: Normally Closed, a switch contact that is closed until it is pressed
*[NO]: Normally Open, a switch contact that is open until it is pressed
*[NPN]: a sensor output that switches its signal line to ground
*[PWM]: Pulse-Width Modulation
*[SPI]: Serial Peripheral Interface, the bus between the microcontroller and the stepper drivers
*[JTAG]: a debug and programming interface
*[SWD]: Serial Wire Debug, the two-wire programming interface of the microcontroller
*[CRC]: Cyclic Redundancy Check
*[GUI]: Graphical User Interface
*[API]: Application Programming Interface
*[E-stop]: Emergency stop
