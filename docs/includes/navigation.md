The header has five tabs. **PAROL6 Robot Manual** is the document you read from the start: the quick start, then
safety, technical data, installation, operation, tools, peripherals, maintenance and troubleshooting, in numbered
chapters, followed by the build guide. **Control Board** is the manual of the electronics inside the base: the
connectors, the stepper drivers, the I/O wiring, the firmware, the serial protocol. **Programming** is the guide
for everyone who writes programs for the robot: the interfaces, the concepts, the Python API, the commander
software and its RBTscript language, ROS 2. **API reference** is where you look things up: every method of the
Python API, read from its source; the RBTscript commands; the serial protocol byte by byte; the firmware parameters.
**Support** says where to get help and how to report a problem.

The whole site describes one PAROL6 release. The dropdown next to the site name switches between releases, and a
page from an older release says so in a bar at the top. The repository card on the right of the header opens the
repository the page belongs to; every page ends with a link to edit it and one to report a problem with it.
