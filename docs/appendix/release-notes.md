# Release notes

## PAROL6

### V1.1 — 2026-11-04

The PAROL6 files as of November 2026, with downloads on the
[release page](https://github.com/Source-Robotics/PAROL6-Desktop-robot-arm/releases/tag/V1.1): the STL files, the
building instructions, the BOM with a reference image for every part, the print table and checksums. Since V1:
the revised building instructions, the small print bed modification for the upper arm and the J1 turret, the
holders for a horizontal and a custom pneumatic gripper, the BOM's current links and images, the URDF and MuJoCo
models from robot_descriptions, and the hardware licence CERN-OHL-S-2.0. The firmware is the same as in V1.

### V1 — 2025-03-08

Stable version of the PAROL6 mechanical files, code, documentation and BOM: the first tagged release of the
[robot repository](https://github.com/Source-Robotics/PAROL6-Desktop-robot-arm/releases/tag/V1). The repository's
main branch continued with BOM updates, the small print bed variants and the community projects list, which
release V1.1 collects; the firmware is unchanged since.
