# 3. RBTscript

RBTscript is the program language of the [commander software](https://docs.source-robotics.com/PAROL-docs/1.1/gui/commander/): one command per
line, run by the commander's interpreter while its GUI shows the robot. It is the quickest way from a taught pose
to a repeating sequence, and it is the limit of what the commander does: for blending, collision checking, tool
selection and a network interface, the [Python API](https://docs.source-robotics.com/PAROL-docs/1.1/programming/02-python-api/).

- [RBTscript](https://docs.source-robotics.com/PAROL-docs/1.1/programming/03-commander/rbtscript/): the language, its units, every command
- [Examples](https://docs.source-robotics.com/PAROL-docs/1.1/programming/03-commander/examples/)

The commander itself, its installation and its windows, is in the [GUI Guide](https://docs.source-robotics.com/PAROL-docs/1.1/gui/).
